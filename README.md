## PIEKARNIK UV
Aktualna wersja piekarnika pozwala na korzystanie z pięciu programów grzania. Urządzenie wyposażone jest w wyłącznik krańcowy, aby zapobiec włączeniu naświetlania z otwartymi drzwiami.
Obudowa urządzenia składa się z podwójnych ścian, które pełnią funkcję kanałów chłodzących dla radiatorów, na których przylutowane są diody uv.
Dodano płytkę ESP32 C3 Super Mini która obsługuje GUI do sterowania przez WIFI, zbiera dane z czujnika uv oraz obsługuje predefioniowane nastawy z karty sd.
